Cindie's Thread Tracker

1. Upload cin-tracker.css to the same GitHub Pages repo as cin-plotter.css and cin-master.css.
2. If the CSS file is placed at the repo root, the Jcink import is:
   https://greenberryhair.github.io/cin-plotter/cin-tracker.css?v=1
3. Use cin-tracker-template.txt as the cleaned Jcink post.
4. When you update the CSS later, bump ?v=1 to ?v=2, ?v=3, etc. to bypass browser/GitHub Pages caching.
